## Security coverage

Enrolled TOTP can no longer be bypassed using a magic link. A password alone cannot satisfy required MFA merely because a passkey is enrolled. Inactive or missing subjects cannot redeem authorization codes, rotate refresh tokens or receive fresh user tokens; deactivation invalidates outstanding codes. Regression tests exercise denied bypasses and valid completed sign-ins. Tests were also checked against the original vulnerable classes and failed as expected.
